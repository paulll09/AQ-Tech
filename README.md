# AQ Tech

Landing de AQ Tech, estudio de desarrollo de software a medida para emprendedores y Pymes.

**En vivo:** [aqtech.com.ar](https://aqtech.com.ar)

## Stack

- [Astro](https://astro.build): sitio estático
- [React](https://react.dev): componentes interactivos (navegación y formulario)
- [Tailwind CSS](https://tailwindcss.com): estilos

## Desarrollo local

Requiere Node `>=22.12` y pnpm.

```sh
pnpm install
pnpm dev      # http://localhost:4321
pnpm build    # genera dist/
```
